# DiscoDrive CLI

[English](../README.md) · [Deutsch](README.de.md) · [Українська](README.uk.md) · [Français](README.fr.md) · [Español](README.es.md) · [**Русский**](README.ru.md) · [Српски](README.sr.md)

**Ваш DiscoDrive из терминала и внутри вашего ИИ-ассистента.**

DiscoDrive CLI — это пара небольших инструментов командной строки для вашего облака [DiscoDrive](https://github.com/discodrive-cloud/discodrive):

- **`dd-cli`** — работа с DiscoDrive прямо из терминала: просмотр и передача файлов, публичные ссылки, а также управление календарём, контактами, задачами, закладками, музыкой и книгами. У каждой команды есть подробный `--help` с примерами.
- **`dd-mcp`** — позволяет ИИ-ассистенту, например Claude, действовать в вашем DiscoDrive за вас. По умолчанию он может читать и добавлять новое (папки, события, задачи, закладки); загрузка файлов, изменение существующих данных и всё, что заставляет сервер обращаться к URL (сохранение страниц, закачки, радио, подкасты), требуют `--allow-changes`.

Вы входите один раз со своей учётной записью DiscoDrive, и оба инструмента её запоминают. В облаке не выполняется ничего, что вы не контролируете, — инструменты просто общаются с вашим собственным сервером.

## Что вы можете делать

### 📁 Файлы

- Просмотр папок, загрузка и скачивание файлов, создание папок, перемещение, переименование и удаление.
- Создание публичных **ссылок для общего доступа** — со сроком действия и доступом только на чтение.
- Всё соответствует тем же файлам и папкам, что вы видите в приложениях DiscoDrive.

### 📅 Календарь, контакты и задачи

- Просмотр и создание **событий календаря**, обзор ближайшей недели, удаление событий.
- Просмотр, добавление и удаление **контактов**.
- Просмотр и добавление **задач**, установка сроков и приоритетов, отметка о выполнении.

### 🔖 Закладки, «прочитать позже» и закачки

- Просмотр и редактирование **закладок браузера**, которые синхронизирует расширение DiscoDrive, — всего дерева целиком, вместе с папками: добавление, переименование, перемещение между папками, удаление.
- Сохранение страницы, чтобы **прочитать позже**: сервер её скачивает, конвертирует в markdown и убирает на хранение; потом читайте её в терминале или перенаправьте в файл.
- Передайте серверу URL, чтобы он **скачал файл за вас**, прямо в вашу папку загрузок, — передача продолжается и после того, как вы закроете ноутбук.

### 🎵 Музыка и 📚 книги

- Просмотр **музыкальной** библиотеки, список и добавление **радиостанций** и **подкастов**, запуск повторного сканирования папки с музыкой.
- Поиск по **библиотеке книг** по автору, серии или жанру, скачивание книги, просмотр и редактирование метаданных.

### 🤖 Ваш ИИ-ассистент внутри вашего облака

- Подключите Claude Desktop, Claude Code или любой другой MCP-совместимый ассистент (Cursor, Zed, VS Code и другие) к вашему DiscoDrive.
- Попросите ассистента найти файл, прочитать заметку, добавить событие в календарь или задачу — он работает с вашими реальными данными.
- **Безопасно по умолчанию:** ассистент может читать, искать и создавать, но загрузка файлов, удаление, перемещение, переименование и всё, что заставляет сервер обращаться к URL, остаются выключенными, пока вы их не разрешите.

### 🌍 Ваш язык

- Интерфейс и сообщения доступны на **7 языках**: английском, немецком, украинском, французском, испанском, русском и сербском.

## Установка

Оба инструмента идут в комплекте: любой из способов установки ниже даёт вам и `dd-cli`, и `dd-mcp`.

### Homebrew (macOS и Linux)

```sh
brew install discodrive-cloud/tap/discodrive-cli
```

Обновляйте потом командой `brew upgrade discodrive-cli`.

### Готовые бинарники

Скачайте архив для вашей системы со страницы [Releases](https://github.com/discodrive-cloud/discodrive-cli/releases) — macOS, Linux и Windows, Intel и ARM. Распакуйте его и положите `dd-cli` и `dd-mcp` в папку из вашего `PATH` (например, `~/bin` или `/usr/local/bin`). Файл `checksums.txt` рядом с архивами позволяет проверить скачанное.

### Через Go

С [Go](https://go.dev/dl/) версии 1.25 или новее:

```sh
go install github.com/discodrive-cloud/discodrive-cli/cmd/dd-cli@latest
go install github.com/discodrive-cloud/discodrive-cli/cmd/dd-mcp@latest
```

Бинарники попадают в `$(go env GOPATH)/bin` — убедитесь, что эта папка есть в вашем `PATH`.

Проверьте установку командой `dd-cli --version`.

## Быстрый старт

```sh
dd-cli login --server https://drive.example   # вход и подключение ИИ-ассистента
dd-cli ls                                      # содержимое корня хранилища
dd-cli put ./report.pdf docs/report.pdf        # загрузить файл
dd-cli get docs/report.pdf                     # скачать файл
dd-cli share docs/report.pdf --expires 24h     # публичная ссылка на 24 часа
```

Сервер с самоподписанным сертификатом? Добавьте `--insecure` к `login` — настройка сохраняется в профиле, и все последующие команды и подключение ассистента используют её автоматически.

Выполните `dd-cli <команда> --help` для подробностей и примеров по любой команде. Несколько повседневных команд:

```sh
dd-cli contacts                                # ваши контакты
dd-cli cal events                              # события на ближайшую неделю
dd-cli tasks add --summary "Позвонить Бобу" --due 2026-07-05T09:00:00Z
dd-cli music list                              # просмотр музыки
dd-cli books list --author "Knuth"             # поиск по библиотеке
dd-cli bookmarks                               # ваше дерево закладок
dd-cli pocket add https://example.org/article  # сохранить страницу, чтобы прочитать позже
dd-cli download add https://example.org/x.iso  # поручить серверу скачать файл
```

У закачек нет списка на сервере, поэтому `dd-cli` ведёт небольшой локальный журнал тех, что поставлены в очередь с этой машины (`downloads.json`, рядом с вашим конфигом). `dd-cli download list` читает его и проверяет каждую запись; `dd-cli download status <id>` работает с любым id, откуда бы он ни был поставлен в очередь.

## Подключение ИИ-ассистента

`dd-cli login` уже подключает Claude за вас. Чтобы изменить подключение позже или подключить других ассистентов:

```sh
dd-cli setup-claude                 # подключить Claude (чтение и создание)
dd-cli setup-claude --allow-changes # разрешить загрузку файлов, изменение существующих данных и обращение к URL
dd-cli print-config                 # вывести фрагмент конфига для любого MCP-клиента
```

После смены режима перезапустите ассистента.

Предпочитаете настроить подключение сами, без установки `dd-cli`? `dd-mcp` самодостаточен:

```sh
dd-mcp login --server https://drive.example    # вход и подключение Claude
dd-mcp                                          # запуск
dd-mcp logout                                   # выход
```

### Удалённый доступ

По умолчанию подключение ассистента локальное и не требует дополнительной настройки. Если вы открываете его по сети, защитите токеном:

```sh
dd-mcp --http 127.0.0.1:8080                       # только локально
dd-mcp --http 0.0.0.0:8080 --http-token <секрет>   # по сети — токен обязателен
```

Сетевой адрес не запустится без токена. Для доступа извне вашей машины поставьте его за reverse-proxy с TLS.

## Язык

Оба инструмента говорят на 7 языках: **en** (по умолчанию), **de**, **es**, **fr**, **ru**, **sr**, **uk**. Язык выбирается по первому заданному источнику:

```sh
dd-cli --lang de ls                 # разово, по-немецки
DISCODRIVE_LANG=fr dd-cli whoami    # через переменную окружения
```

Иначе используется системная локаль (`LC_ALL` / `LANG`), а при её отсутствии — английский.

## Безопасность файлов и календаря

Скачивание заменяет локальный файл только после успешного завершения передачи и
закрытия файла. Перемещение с переименованием одной командой `mv` требует сервер
с атомарным API `PATCH /files/{id}/relocate`. На старом сервере команда возвращает
ошибку, не перемещая файл частично.

Инструмент MCP `dd_files_read` читает до 1 МиБ текста. Для больших файлов
используйте `dd-cli get`. Для `dd_files_upload` требуется `--allow-changes`,
поскольку загрузка может заменить существующий файл.

Для повторяющихся событий укажите `--tz Europe/Berlin` (в MCP — `tz`), чтобы
сохранить местное время встречи при переходе на летнее или зимнее время.
По умолчанию используется системный пояс IANA; если определить его невозможно,
укажите пояс явно. `--until 2026-10-10` означает последний день серии включительно.
Имеющийся у события именованный часовой пояс сохраняется сервером.

## Безопасность

- **Что хранится на вашей машине.** `dd-cli login` сохраняет токен устройства в `~/.config/discodrive/cli.json` (читать его можете только вы); короткоживущий токен сессии кэшируется в `~/.cache/discodrive/`. Любой, кто может прочитать эти файлы, может действовать в DiscoDrive от вашего имени, — не давайте к ним доступ.
- **Выход.** `dd-cli logout` (или `dd-mcp logout`) отзывает устройство на сервере и забывает его локально. Потерянное устройство также можно отключить в веб-приложении DiscoDrive, в разделе «Настройки».
- **Используйте https.** С обычным адресом `http://` токен и ваши данные передаются без шифрования; `login` предупреждает об этом. `--insecure` лишь отключает проверку сертификата для самоподписанного сервера, которому вы доверяете.
- **Один вход на сервер.** `--server` выбирает сохранённый вход для этого адреса; токен никогда не отправляется серверу, который его не выдавал.
- **ИИ-ассистенты и недоверенное содержимое.** Сохранённые веб-страницы и общие файлы могут содержать текст, написанный, чтобы манипулировать ассистентом (prompt injection). Поэтому изменения, загрузки и всё, что заставляет сервер обращаться к URL, требуют `--allow-changes`. Включайте его, только если доверяете тому, что читает ассистент, и проверяйте, что он делает.
- **Удалённый доступ.** `dd-mcp --http` остаётся на `127.0.0.1`, пока вы не зададите токен; см. [Удалённый доступ](#удалённый-доступ).

**Сообщить об уязвимости:** пожалуйста, напишите на [info@discodrive.app](mailto:info@discodrive.app), а не открывайте публичный issue.
