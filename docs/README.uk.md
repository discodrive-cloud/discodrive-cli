# DiscoDrive CLI

[English](../README.md) · [Deutsch](README.de.md) · [**Українська**](README.uk.md) · [Français](README.fr.md) · [Español](README.es.md) · [Русский](README.ru.md) · [Српски](README.sr.md)

**Ваш DiscoDrive із термінала — і всередині вашого ШІ-асистента.**

DiscoDrive CLI — це пара невеликих інструментів командного рядка для вашої хмари [DiscoDrive](https://github.com/discodrive-cloud/discodrive):

- **`dd-cli`** — робота з DiscoDrive прямо з термінала: перегляд і передавання файлів, публічні посилання, а також керування календарем, контактами, завданнями, закладками, музикою та книгами. Кожна команда має докладний `--help` із прикладами.
- **`dd-mcp`** — дозволяє ШІ-асистенту, наприклад Claude, діяти у вашому DiscoDrive за вас. За замовчуванням він може читати й додавати нове (папки, події, завдання, закладки); вивантаження файлів, зміни наявних даних і все, що змушує сервер звертатися до URL (збереження сторінок, завантаження, радіо, подкасти), потребують `--allow-changes`.

Ви входите один раз зі своїм обліковим записом DiscoDrive, і обидва інструменти його запамʼятовують. У хмарі не виконується нічого, що ви не контролюєте, — інструменти просто спілкуються з вашим власним сервером.

## Що ви можете робити

### 📁 Файли

- Перегляд папок, завантаження та вивантаження файлів, створення папок, переміщення, перейменування й видалення.
- Створення публічних **посилань для спільного доступу** — зі строком дії та доступом лише для читання.
- Усе відповідає тим самим файлам і папкам, які ви бачите в застосунках DiscoDrive.

### 📅 Календар, контакти та завдання

- Перегляд і створення **подій календаря**, огляд найближчого тижня, видалення подій.
- Перегляд, додавання та видалення **контактів**.
- Перегляд і додавання **завдань**, встановлення строків і пріоритетів, позначення виконаними.

### 🔖 Закладки, «прочитати пізніше» та завантаження

- Перегляд і редагування **закладок браузера**, які синхронізує розширення DiscoDrive, — усього дерева цілком, разом із папками: додавання, перейменування, переміщення між папками, видалення.
- Збереження сторінки, щоб **прочитати пізніше**: сервер її завантажує, конвертує в markdown і відкладає на зберігання; потім читайте її в терміналі або перенаправте у файл.
- Передайте серверу URL, щоб він **завантажив файл за вас**, просто до вашої папки завантажень, — передавання триває й після того, як ви закриєте ноутбук.

### 🎵 Музика та 📚 книги

- Перегляд **музичної** бібліотеки, список і додавання **радіостанцій** та **подкастів**, запуск повторного сканування папки з музикою.
- Пошук у **бібліотеці книг** за автором, серією чи жанром, завантаження книги, перегляд і редагування метаданих.

### 🤖 Ваш ШІ-асистент усередині вашої хмари

- Підключіть Claude Desktop, Claude Code або будь-який інший MCP-сумісний асистент (Cursor, Zed, VS Code та інші) до вашого DiscoDrive.
- Попросіть асистента знайти файл, прочитати нотатку, додати подію до календаря чи завдання — він працює з вашими реальними даними.
- **Безпечно за замовчуванням:** асистент може читати, шукати й створювати, але вивантаження файлів, видалення, переміщення, перейменування та все, що змушує сервер звертатися до URL, лишаються вимкненими, доки ви їх не дозволите.

### 🌍 Ваша мова

- Інтерфейс і повідомлення доступні **7 мовами**: англійською, німецькою, українською, французькою, іспанською, російською та сербською.

## Встановлення

Обидва інструменти постачаються разом: будь-який зі способів встановлення нижче дає вам і `dd-cli`, і `dd-mcp`.

### Homebrew (macOS і Linux)

```sh
brew install discodrive-cloud/tap/discodrive-cli
```

Оновлюйте потім командою `brew upgrade discodrive-cli`.

### Готові бінарні файли

Завантажте архів для вашої системи зі сторінки [Releases](https://github.com/discodrive-cloud/discodrive-cli/releases) — macOS, Linux і Windows, Intel і ARM. Розпакуйте його та покладіть `dd-cli` і `dd-mcp` у папку з вашого `PATH` (наприклад, `~/bin` або `/usr/local/bin`). Файл `checksums.txt` поруч з архівами дає змогу перевірити завантажене.

### Через Go

З [Go](https://go.dev/dl/) 1.25 або новішим:

```sh
go install github.com/discodrive-cloud/discodrive-cli/cmd/dd-cli@latest
go install github.com/discodrive-cloud/discodrive-cli/cmd/dd-mcp@latest
```

Бінарні файли потрапляють до `$(go env GOPATH)/bin` — переконайтеся, що ця папка є у вашому `PATH`.

Перевірте встановлення командою `dd-cli --version`.

## Швидкий старт

```sh
dd-cli login --server https://drive.example   # вхід і підключення ШІ-асистента
dd-cli ls                                      # вміст кореня сховища
dd-cli put ./report.pdf docs/report.pdf        # вивантажити файл
dd-cli get docs/report.pdf                     # завантажити файл
dd-cli share docs/report.pdf --expires 24h     # публічне посилання на 24 години
```

Сервер із самопідписаним сертифікатом? Додайте `--insecure` до `login` — налаштування зберігається у профілі, і всі подальші команди та підключення асистента використовують його автоматично.

Виконайте `dd-cli <команда> --help` для подробиць і прикладів щодо будь-якої команди. Кілька щоденних команд:

```sh
dd-cli contacts                                # ваші контакти
dd-cli cal events                              # події на найближчий тиждень
dd-cli tasks add --summary "Зателефонувати Бобу" --due 2026-07-05T09:00:00Z
dd-cli music list                              # перегляд музики
dd-cli books list --author "Knuth"             # пошук у бібліотеці
dd-cli bookmarks                               # ваше дерево закладок
dd-cli pocket add https://example.org/article  # зберегти сторінку, щоб прочитати пізніше
dd-cli download add https://example.org/x.iso  # доручити серверу завантажити файл
```

Для завантажень немає списку на сервері, тож `dd-cli` веде невеликий локальний журнал тих, що поставлені в чергу з цієї машини (`downloads.json`, поруч із вашою конфігурацією). `dd-cli download list` читає його й перевіряє кожен запис; `dd-cli download status <id>` працює з будь-яким id, звідки б його не поставили в чергу.

## Підключення ШІ-асистента

`dd-cli login` уже підключає Claude за вас. Щоб змінити підключення пізніше або підключити інших асистентів:

```sh
dd-cli setup-claude                 # підключити Claude (читання і створення)
dd-cli setup-claude --allow-changes # дозволити вивантаження файлів, зміни наявних даних і звернення до URL
dd-cli print-config                 # вивести фрагмент конфігурації для будь-якого MCP-клієнта
```

Після зміни режиму перезапустіть асистента.

Волієте налаштувати підключення самі, без встановлення `dd-cli`? `dd-mcp` самодостатній:

```sh
dd-mcp login --server https://drive.example    # вхід і підключення Claude
dd-mcp                                          # запуск
dd-mcp logout                                   # вихід
```

### Віддалений доступ

За замовчуванням підключення асистента локальне й не потребує додаткового налаштування. Якщо ви відкриваєте його мережею, захистіть токеном:

```sh
dd-mcp --http 127.0.0.1:8080                       # лише локально
dd-mcp --http 0.0.0.0:8080 --http-token <секрет>   # мережею — токен обовʼязковий
```

Мережева адреса не запуститься без токена. Для доступу ззовні вашої машини поставте її за reverse-proxy з TLS.

## Мова

Обидва інструменти розмовляють 7 мовами: **en** (за замовчуванням), **de**, **es**, **fr**, **ru**, **sr**, **uk**. Мова обирається за першим заданим джерелом:

```sh
dd-cli --lang de ls                 # разово, німецькою
DISCODRIVE_LANG=fr dd-cli whoami    # через змінну середовища
```

Інакше використовується системна локаль (`LC_ALL` / `LANG`), а за її відсутності — англійська.

## Безпека передавання файлів і календаря

Завантаження замінює локальні файли лише після того, як успішно завершено все
передавання та закриття файлу. Переміщення з перейменуванням однією командою `mv`
потребує сервера з атомарним ендпоінтом `PATCH /files/{id}/relocate`. Старіші сервери
повертають помилку, нічого не переміщуючи; запасного варіанта з частковим переміщенням немає.

MCP `dd_files_read` приймає до 1 МіБ тексту. Для більших файлів використовуйте `dd-cli get`.
`dd_files_upload` потребує `--allow-changes`, оскільки вивантаження може перезаписати файл.

Для повторюваних подій календаря використовуйте `--tz Europe/Berlin` (у MCP — `tz`), щоб
зберегти місцевий час зустрічей під час переходу на літній чи зимовий час. Нові серії за
замовчуванням використовують пояс IANA машини; якщо його неможливо визначити, вкажіть пояс
явно. `--until` — це остання календарна дата включно, наприклад `--until 2026-10-10`.
Наявний у події іменований часовий пояс сервер зберігає.

## Безпека

- **Що зберігається на вашій машині.** `dd-cli login` зберігає токен пристрою в `~/.config/discodrive/cli.json` (читати його можете лише ви); короткочасний токен сесії кешується в `~/.cache/discodrive/`. Будь-хто, хто може прочитати ці файли, може діяти в DiscoDrive від вашого імені, — не давайте до них доступу.
- **Вихід.** `dd-cli logout` (або `dd-mcp logout`) відкликає пристрій на сервері й забуває його локально. Загублений пристрій також можна відʼєднати у вебзастосунку DiscoDrive, у розділі «Налаштування».
- **Використовуйте https.** Зі звичайною адресою `http://` токен і ваші дані передаються без шифрування; `login` попереджає про це. `--insecure` лише вимикає перевірку сертифіката для самопідписаного сервера, якому ви довіряєте.
- **Один вхід на сервер.** `--server` вибирає збережений вхід для цієї адреси; токен ніколи не надсилається серверу, який його не видавав.
- **ШІ-асистенти та недовірений вміст.** Збережені вебсторінки та спільні файли можуть містити текст, написаний, щоб маніпулювати асистентом (prompt injection). Саме тому зміни, вивантаження та все, що змушує сервер звертатися до URL, потребують `--allow-changes`. Вмикайте його, лише якщо довіряєте тому, що читає асистент, і перевіряйте, що він робить.
- **Віддалений доступ.** `dd-mcp --http` лишається на `127.0.0.1`, доки ви не задасте токен; див. [Віддалений доступ](#віддалений-доступ).
